APTARA CONTENT SHELF — MVP 0.3 UAT PACK

1. Extract this ZIP into its own folder.
2. Open index.html in Chrome to try the app.
3. IDs: choose Prepare content, import a completed Word storyboard, review, and export handoff.
   Developers: choose Build in Rise, open the handoff file, launch the companion, copy and mark inserted.
4. Open uat.html for the checklist and results report.
5. Export your project JSON and download your UAT report before moving files or clearing browser data.

The hosted version is preferred for consistent browser storage and companion synchronization. Local HTML files can have browser-specific clipboard/storage behavior. If copying is unavailable, select and copy text manually or use the hosted version.

Only one active project is stored per browser/site. No content or feedback is submitted automatically. Word import supports the supplied Rise storyboard format. Plain text only; no automatic Rise insertion. The companion cannot stay always on top. Use approved sample content for UAT.

To return feedback: open uat.html, fill in test results, download results (.txt or .json), and send the downloaded file to your UAT coordinator. Attach only approved project content and screenshots.
